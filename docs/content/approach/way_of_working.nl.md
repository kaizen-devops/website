# Manier van Werken

Doelgericht, stap voor stap, kaizen-stijl: kleine, bewuste verbeteringen in plaats van big-bang overhauls.

- **Agile, in sprints** — korte feedbackloops, werkende resultaten boven papierwerk.
- **Begin klein, schaal slim** — bewijs snel waarde, groei daarna wat werkt.
- **Eerst luisteren** — elk traject begint met begrijpen wat er echt toe doet, voordat er een regel code geschreven wordt.
- **Automatiseer het saaie werk** — Infrastructure as Code en CI/CD, zodat teams zich kunnen focussen op wat ertoe doet.
- **Open, geen lock-in** — open-source tools en standaarden boven vendor lock-in.
- **Heldere communicatie** — simpel, efficiënt, transparant, in elke stap.
